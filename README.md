# Projectile Motion Game
This was a project made for the "Shrink" HackClub YSWS, a YSWS with the premise of creating a working app in under 3KiB using data URIs. 

This project was made based off of the simulation provided by phet.colorado.edu and furthered into a gamified aspect through the scoring system, audio aspects and random targets. Further updates are planned in the future to improve the graphics and the game-y nature.

This was created using help from the Shrink guide @ https://shrink.hackclub.com/app/guides/writing and https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API.
